PREREG (2026-09-23) — go_swe_bench v0: the SYSTEM-PROMPT repair.
"The writer was told to fix the bug, in the one channel it was never shown"
=========================================================================================
Written and committed BEFORE either redraw below. Author: Vefa.

THE DEFECT (found while preparing the training arm, not looked for).
  swe_bench_eval.ask() builds the request with the module-global SYSTEM. The self-test writer and the
  decledit loop import swe_bench_eval as `h` and call h.ask(); each defines its own SYSTEM, which was
  therefore never sent. What the model received, in every draw since ff5800d (2026-09-20):
    system: "...fixing a bug in a real repository... Return EVERY given file in full, each in its own
             ```go block whose first line is // file: <path>... Change only what the fix needs."
    user  (writer): "...Write the test file for package X. Its tests must fail on the code above..."
    user  (loop):   "...Return only the declarations you change or add."
  Evidence already in the archive: in the first writer draw, 16/51 outputs contain no TestXxx, and all
  16 carry a `// file:` header naming a NON-test file -- the model obeyed the system turn and returned
  the fixed source. In the exemplar draw, 0/51 do. The form-retry arm's "16/16 converted in one turn"
  was a user turn out-shouting a system turn.
  Verified at the network layer (urlopen patched): before the fix, writer and loop sent the eval
  prompt; after, each sends its own, and swe_bench_eval sends its own unchanged.

AFFECTED: every self-test writer draw (selftest arm, form-retry, exemplar, compile-retry, and the
  isolation rescore, which replays their tests) and every decledit loop draw (algorithm arm, self-test
  loop, 30B and 7B). NOT affected: swe_bench_eval.py file-level baselines (11/51, 9/51), the router
  line of 2026-09-19 (other scripts), the gold probes (--model hidden, no model call).
  The recorded numbers stay true as "what this harness did". None of them measured the registered
  prompt.

THE FIX: ask(..., system=None); writer and loop pass system=SYSTEM on all 4 call sites. Nothing else
  in either script changes.
