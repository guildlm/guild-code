FINDINGS:
  1. The test signal is REAL but the bottleneck is the test writer's FORM, not its judgement. The
     best code model wrote a function in 42/48 test files. One AST repair turned 2 valid tests
     into 21 and bought the router its point. The algorithm's cheapest component (deterministic
     repair) again did the work the weights would not.
  2. A wrong self-test is worse than none: it fails every candidate (no signal) or fails the
     right one (wrong signal). STRICT's "must discriminate" rule is what made the wrong tests
     harmless tonight; LOOSE would have equalled it only because fallback stayed on 30B.
  3. Validity on the reference (21/48 at best) is the ceiling on how much of the union a
     self-test can cash. The next lever is the TEST WRITER, not the router: a test-writing
     prompt/role that never re-implements (form) and asserts only what the spec states
     (judgement), measured by validity-on-reference before it is ever used to route.
  4. The go-test specialist question is re-opened from a new side: 2026-07-21 showed its edge
     was a VALIDITY premium the base+goimports also had. Tonight validity is exactly the scarce
     resource. A test writer worth training is one that raises validity-on-reference, and that is
     a measurable target with a deterministic scorer — no LLM judge.
