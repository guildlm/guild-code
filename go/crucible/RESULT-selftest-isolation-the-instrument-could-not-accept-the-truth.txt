(E) THREE DEFECTS OF MY OWN, EACH CAUGHT BY THE GATE AND EACH NAMED.
  1. FIRST FORM OF THE RULE: delete the fix's test files by name, keep the rest. The acceptance gate
     came back 16 -> 23, WORSE. Cause: pkgdir is "." for a root package while a root path's dirname
     is "", so the comparison silently exempted every root-package task and the gold file survived
     next to its own copy — 10 rows of "redeclared in this block". A path comparison that is only
     correct off the root is the same family as every defect this kit found this week.
  2. SECOND FORM, after normalizing: gate 16 -> 9, but 6 scored writer rows turned into 'error',
     because deleting the fix's test file broke every sibling that used a helper defined in it.
     Deleting for safety was never necessary: the worktree is `git worktree add --detach <parent>`
     and the gold arrives WITH THE FIX, so it is not on disk at all. The final rule deletes nothing
     for leakage and deletes a file only when it would REDECLARE a name the self-test declares.
     Gate 16 -> 10, writer rows broken: 1.
  3. THE ARCHIVE'S OWN RECORD WAS INVERTED. In the compile-retry arm, row["output"] was overwritten
     with the retry text unconditionally — including when the retry was DISCARDED for having no
     TestXxx. So on those rows the record kept the discarded text as "output" and filed the SCORED
     text under "compile_rejected". --rescore was the first consumer to read "output" as the answer
     and it silently re-derived a different program on 3 rows (fzf, act, rqlite), which showed up as
     3 phantom "no-test" verdicts in the first rescore table. Fixed twice: the writer no longer
     overwrites a discarded retry (it records compile_discarded), and --rescore now replays the
     SCORED TEST when the earlier row carries one. An instrument A/B must replay the artifact that
     was scored, not the last text the model happened to produce.

FINDINGS.
  1. An instrument that cannot accept the known-correct answer is not measuring what it claims. The
     probe that proves it (--model hidden through the self-test path) already existed and had been
     run; its 16 nocompile rows sat in data/ unread while three arms were spent above them. Running
     a probe is not the same as reading it.
  2. Isolation was implemented as deletion when it only ever needed to be construction. The gold was
     already absent by virtue of the checkout; everything the deletion removed beyond that was cost.
  3. The writer does not use the fixtures. Given them back, it wrote exactly the same tests. So the
     invented-symbol class is NOT a fixture-access problem, and the retrieval lever that worked
     (a neighbouring test file) worked by showing the model HOW to write, not WHAT to call.
  4. Every number this line quotes needs its denominator restated: 9 tasks are unreachable by
     construction and 3 more have no test block in the gold. The bench is 51 rows and 38 of them
     are answerable.
